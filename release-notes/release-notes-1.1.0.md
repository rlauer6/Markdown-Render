# Markdown::Render 2.1.0 Release Notes

**Release Date:** 2026-07-23

---

## Overview

This minor release is a significant infrastructure overhaul driven by
adoption of `CPAN::Bootstrapper::Maker`. The legacy hand-rolled
`cpan/` build sub-tree has been retired and replaced with a fully
bootstrapped build pipeline. A new `markdown-render` command replaces
`md-utils.pl`, which is now deprecated. Dependency management has been
tightened with explicit version pins on several new and existing
runtime requirements.

---

## Breaking Changes

### `md-utils.pl` Deprecated

`md-utils.pl` now emits a deprecation warning and immediately `exec`s
`markdown-render`. The full CLI implementation previously contained in
`bin/md-utils.pl.in` has been removed. Users should migrate to
`markdown-render`.

```
md-utils.pl is deprecated. use markdown-render
```

### Legacy `cpan/` Sub-tree Removed

The following files have been deleted:

- `cpan/Makefile` — replaced by the top-level bootstrapped `Makefile`
- `cpan/provides` — superseded by `CPAN::Bootstrapper::Maker` tooling
- `cpan/requires` — moved to the top-level `requires` file

---

## New Features

### `markdown-render` Command

A new `bin/markdown-render.in` script is introduced as the canonical
replacement for `md-utils.pl`.

### New `Markdown::Render::CLI` Module

`lib/Markdown/Render/CLI.pm.in` has been updated as a dedicated CLI
module, separating concerns from the core `Markdown::Render` class.

### Bootstrapped Build System

The `Makefile` has been entirely replaced by a
`CPAN::Bootstrapper::Maker`-managed build. New infrastructure files
introduced:

| File | Purpose |
|------|---------|
| `buildspec.yml` | Build specification for `cpan-maker` |
| `config.mk` | Local build configuration |
| `deps.mk` | Auto-generated dependency graph |
| `cpanfile` | Generated by `CPAN::Bootstrapper::Maker` |
| `recommends` | Soft dependency tier |
| `suggests` | Optional dependency tier |
| `test-requires` | Test-only dependency tier |
| `.includes/git.mk` | Git helpers |
| `.includes/help.mk` | `make help` target support |
| `.includes/perl.mk` | Perl build rules |
| `.includes/release-notes.mk` | Release notes target |
| `.includes/update.mk` | Update checking |
| `.includes/upgrade.mk` | Upgrade support |
| `.includes/version.mk` | Version bump targets (moved from `version.mk`) |

The old top-level `version.mk` and `release-notes.mk` files have been
removed; their functionality is now provided by the `.includes/`
variants.

## Changes

### `Markdown::Render` (`lib/Markdown/Render.pm.in`)

- Module modified as part of the bootstrapped build refactor.
- File mode changed from executable (`0755`) to regular (`0644`).

### `README.md`

- Regenerated from module POD via `pod2markdown` + `md-utils.pl`.
- Content restructured to reflect the module's API documentation
  (NAME, SYNOPSIS, DESCRIPTION, METHODS AND SUBROUTINES) rather than
  the previous project-oriented README format.

### Test Suite (`t/00-markdown.t`)

- Refactored for simplicity.
- Test input file now read from the distribution root `README.md`
  rather than a fixture file at `t/files/README.md.in`, removing the
  need to locate the file across multiple candidate paths.
- Switched from a fixed `plan tests =>` count to `done_testing`.
- Trailing `__DATA__` sentinel removed.

A new test file `t/00-markdown-render.t` has been added.

### `.gitignore`

- Fully regenerated by `CPAN::Bootstrapper::Maker`.
- Now ignores generated artifact patterns: `**/*.pl`, `**/*.pm`,
  `**/*.sh`, `**/*.raw`, `**/*.crit`, `**/*.tdy`, `*.gz`, `*.log`,
  `*.tmp`, and build review files.
- Previous patterns for `cpan/` sub-directories removed.

## Upgrade Notes

- Users invoking `md-utils.pl` directly will see a deprecation warning
  on `STDERR` and execution will continue via
  `markdown-render`. Update any scripts or `Makefile` rules that call
  `md-utils.pl` to use `markdown-render` instead.
- The `cpan/` directory and its contents should be removed from any
  local working trees; they are no longer part of the distribution.
- Building from source now requires `CPAN::Maker::Bootstrapper` to be
  installed (`cpanm CPAN::Maker::Bootstrapper`).
